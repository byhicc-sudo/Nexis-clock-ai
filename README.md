# NEXİS Clock AI

Yesido iO50 Bluetooth keşfi ve NEXİS CEO AI Android laboratuvar prototipi.

> **Durum:** Kaynak kodu prototipi. Saat üzerinden konuşma, bildirim gönderimi, kadran yazma ve firmware güncelleme bu sürümde yoktur. Sunucu kurulmadan AI sohbeti çalışmaz.

- `android/`: Android uygulaması
- `server/`: İnsan onaylı yapay zekâ API örneği
- `.github/workflows/android-apk.yml`: GitHub Actions ile debug APK oluşturma
- `TELEFONDAN_BASLAT.md`: Sadece telefon ile başlatma

**Güvenlik:** Gizli anahtarlar, gerçek müşterilere ait veriler, şifreler ve muhasebe bilgileri bu herkese açık depoya konulmamalıdır.
