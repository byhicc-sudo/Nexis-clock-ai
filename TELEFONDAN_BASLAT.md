# Telefonda NEXİS CEO AI başlatma

1. GitHub'da byhicc-sudo/Nexis-clock-ai deposunu aç.
2. Actions sekmesine gir.
3. NEXIS CEO AI - Android APK iş akışını aç.
4. Run workflow -> main -> Run workflow seç.
5. İş akışı yeşil başarıyla tamamlanırsa ilgili koşuyu aç.
6. Artifacts kısmında NEXIS-CEO-AI-v0.1-debug ZIP dosyasını indir.
7. ZIP'i telefonda aç ve app-debug.apk dosyasını çıkar.
8. APK'yı kur. Android yalnızca bu kurulum için izin isterse güvenilirliği doğrulayıp izin ver.
9. Uygulamayı aç, Bluetooth izinlerini ver, Yesido IO50'yi tara ve bağlan.

Bu aşamada sadece BLE tarama/servis keşfi çalışması hedefleniyor; saate firmware veya özel veri gönderilmiyor.
Yapay zekâ sohbeti ayrı HTTPS sunucusu ve sunucuda OPENAI_API_KEY gerektirir.
Sunucu bağlanmadan sohbet yanıtı oluşmaz; bu konuşma geçmişi uygulamaya otomatik aktarılmaz.
Gerçek müşteri verilerini bu laboratuvar sürümüne ekleme.
